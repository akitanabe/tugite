Flow

判断までの主経路

主経路を横に追い、各 step の条件や例外は近くで確認できます。狭い画面では同じ読み順のまま縦に並びます。

入力から結果まで

  1. 1 viz:flow-input

    入力を確認する

    事実、関係、制約、不確実性を読み取ります。

  2. 2 viz:flow-compose

    構成を決める

    中心命題と primary structure を定めます。

    この step の詳細

    Supporting detail は主経路との関係が分かる位置に置きます。長い識別子も折り返して表示します。

  3. 3 viz:flow-build

    HTML を組む

    本文と関係を markup と CSS で表します。

  4. 4 viz:flow-result

    結果を確認する

    意味保持と表示範囲を実物で確認します。

局所 cycle

修正↔再確認

条件による branch

分岐元: 入力を確認する。意味を確定できるかで、次の行き先を選びます。
