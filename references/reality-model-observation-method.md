# Reality Model Observation Method

## Status

**Established — canonical method.**

本 Method は、与えられた Target に対して **Observable Reality Model** を導出し、
そのモデルを用いて Reality を観測し、Target-relative な discrepancy と Problem を導出するための方法を定義する。

本 Method の責務は **Problem Derivation まで**である。

観測された問題の修正、改善案の生成、Target の変更、次の Improvement Loop の開始は本 Method の責務ではない。
