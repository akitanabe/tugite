Relationship

要素間の関係をたどる

中心 node と接続先を分け、線が表す関係を各 node の本文でも確認できます。

情報の受け渡し

viz:relation-source

入力元

観測した Data を判断へ渡します。

Data を渡す

viz:relation-hub

判断

入力を分類し、条件に応じて記録または通知を選びます。

条件に応じて分岐する

判断から独立した二つの宛先

viz:relation-record

分岐先 A: 記録

保持する Data がある場合に、判断から直接受け取ります。

viz:relation-notify

分岐先 B: 通知

伝達する内容がある場合に、判断から直接受け取ります。

各宛先の結果をまとめる

viz:relation-result

結果

選ばれた宛先の結果を読者へ返します。

関係: 入力元から判断へ Data を渡し、判断から記録または通知へ分岐します。記録と通知の間に順序や依存はありません。
